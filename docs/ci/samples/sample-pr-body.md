# Teaching sample: Public property share preview

## What this change introduces

This pull request adds a standalone TypeScript example of a public property sharing preview for PREIShare. It uses fictional property and member information for review practice.

## Why this is being submitted

This is a teaching example for practicing AI-assisted and human code reviews. It is not part of the actual PREIShare application and should not be used in production.

## What reviewers should examine

Reviewers should examine the example for possible privacy risks, how member information is handled, and whether the public preview shares appropriate information.

Reviewers should follow the existing PREIShare review documents:

- `docs/ci/ai-review-orchestration.md` explains the review process and the order of steps.
- `docs/ci/human-judgment-checklist.md` explains how humans evaluate privacy and other risks.
- `docs/ci/pr-approval-roles.md` explains who has approval and merge authority.

AI review findings are suggestions only. Reviewers should use the existing documents to make their decisions.

This pull request is for teaching purposes and must remain open and unmerged.
