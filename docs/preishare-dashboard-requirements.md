# PREIshare Dashboard Requirements

## Product Summary

PREIshare is building an investor dashboard shell that gives investors a quick,
trustworthy view of important investment information. This sprint delivers a
demoable frontend with layout, navigation, summary metrics, recent activity, and
mock or placeholder content. It does not connect to live data.

## Primary User

The primary user is an investor viewing PREIshare's dashboard.

## Must-Have Shell Areas

- **Header:** A visible header at the top of the dashboard shell.
- **Navigation:** Clear navigation for moving through the dashboard.
- **Metrics:** A quick overview with portfolio value or similar summary metrics,
  including open deals.
- **Activity:** A recent activity area with mock or placeholder entries.

## Investor Goals

- Get a quick overview of important investment information.
- See portfolio value or similar summary metrics and open deals.
- Review recent activity.
- Find dashboard areas through clear navigation.

## Must Have This Sprint

- A frontend dashboard shell that can be demonstrated in a browser.
- The header, navigation, metrics, and activity areas.
- A quick overview of portfolio value or similar summary metrics and open deals.
- Mock or placeholder content only.

## Later / Out of Scope

- Real authentication.
- Live portfolio data or database-backed data.
- Payments or wire transfers.
- Tax reports.
- Admin tools.
- Real financial calculations.

## Success Criteria

- The dashboard shell opens in a browser.
- The browser view shows the header, navigation, metrics, and recent activity.
- The overview shows a portfolio value or similar summary metric and open deals.
- The recent activity area shows mock or placeholder entries.
- Navigation is visible, and its links can be selected in the browser.
- No live portfolio data, database-backed data, or real financial calculations
  are required for the demo.
