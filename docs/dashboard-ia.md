# PREIshare Investor Dashboard Information Architecture

The dashboard provides persistent navigation across four investor areas. All content is mock or placeholder data.

| URL | Page | Navigation Label | Page Purpose | Primary Content |
|---|---|---|---|---|
| `/dashboard` | Dashboard Home | Home | Quickly scan portfolio value and recent activity. | Placeholder stats, portfolio summary, recent activity. |
| `/dashboard/portfolio` | Portfolio | Portfolio | Review the investor's current holdings. | Mock investment list or table. |
| `/dashboard/deals` | Deals | Deals | Browse deals that are open or available. | Mock list of open or available deals. |
| `/dashboard/profile` | Profile | Profile | View basic investor information. | Placeholder investor name and contact details. |
